Solving Multi-Stpe Problem using variables:
A Grocery store sells a bag of ice $1.25 and makes 20% profit. if it sells 500 bags of ice. how much total profit does it make? We can list out the information provided, and Gradually word problem into a mathematical expression Which  can be evaluated using python.

Cost of ice bag = $1.25
Profit Margin = 20% = 20/100
Profit per bag = profit margin * cost of ice bag = 2*1.25 
Number of bags = 500
Total Profit = $(2*1.25) * 500
